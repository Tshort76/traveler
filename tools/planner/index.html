Coverage tracks departure and arrival ground journeys for each flight record. Connections inside a flight record need separate review. A row marked Research still needs action.

Local files

The project JSON holds the current trip and the last exchange baseline. Research is part of the trip’s optional planning data and travels with its bookings.

Save JSON writes a project file. Export to Traveler writes a trip revision; save the project afterwards to retain that exchange baseline. Import phone edits compares that export against your desktop changes before applying anything.

A browser draft is a recovery copy, not your project file. Older Android builds ignore planning details; use the updated app to preserve them through phone export.
